# Proyecto 1: Pruebas Manuales de SauceDemo

## 1. Presentación del proyecto

Este proyecto forma parte de mi portafolio de QA Testing y tiene como finalidad poner en práctica los conocimientos
adquiridos en el área de aseguramiento de la calidad del software mediante el diseño y la ejecución de pruebas manuales.

El proyecto se desarrolla sobre SauceDemo, una aplicación web de demostración que permite practicar pruebas funcionales 
relacionadas con el inicio de sesión y el comportamiento del sistema ante diferentes datos de entrada.

## 2. Objetivo

Verificar que la funcionalidad de inicio de sesión responda correctamente ante diferentes escenarios, comprobando que los 
usuarios puedan acceder cuando utilizan credenciales válidas y que el sistema gestione adecuadamente los intentos de acceso no válidos.

## 3. Aplicación evaluada

- **Aplicación:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Área evaluada:** Inicio de sesión (Login).
- **Tipo de pruebas:** Pruebas funcionales manuales.
- **Enfoque:** Escenarios positivos y negativos.

## 4. Alcance de las pruebas

Durante esta etapa se diseñaron y ejecutaron cuatro casos de prueba:

1. Inicio de sesión con credenciales válidas.
2. Inicio de sesión con contraseña incorrecta.
3. Intento de inicio de sesión con los campos vacíos.
4. Intento de inicio de sesión con un usuario bloqueado.

## 5. Herramientas utilizadas

- SauceDemo: aplicación bajo prueba.
- Microsoft Excel: registro y seguimiento de los casos de prueba.
- Capturas de pantalla: evidencias de ejecución.

## 6. Documentación y evidencias

El proyecto incluye una plantilla de Excel con los casos de prueba, precondiciones, pasos, datos de prueba, resultados esperados, 
resultados obtenidos, estados y observaciones.

También incluye capturas de pantalla asociadas a los casos ejecutados, cuando corresponda.

## 7. Aprendizajes obtenidos

Esta práctica permite reforzar habilidades de diseño de casos de prueba, validación de resultados, ejecución de escenarios positivos y 
negativos, documentación de evidencias y organización de información de QA.

## 8. Conclusión

Este proyecto representa una práctica de aplicación de los fundamentos de pruebas manuales de software. Su propósito es demostrar mi 
capacidad para estructurar casos de prueba, ejecutarlos de manera ordenada y documentar los resultados de forma clara y profesional.




## 9. Resumen de ejecución

Se diseñaron y ejecutaron cuatro casos de prueba relacionados con la funcionalidad de inicio de sesión de SauceDemo.

- Total de casos diseñados: 4.
- Casos aprobados (Passed): [4].
- Casos fallidos (Failed): [0].
